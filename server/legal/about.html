About Pinball Genie

A study tool for learning a pinball machine's shot paths, so you play better the next time you step up to it.

Why it exists

Pinball rewards knowing the machine — which shots matter, in what order, and how the playfield is laid out. Most of that knowledge is normally learned the slow way: playing the same machine over and over, or reading dense rulesheets on a phone between balls. Pinball Genie exists to shorten that curve. Study a machine before you play, and the shots make a lot more sense.

What it covers

The catalog spans more than a hundred machines across modern Stern titles, Spooky Pinball, Chicago Gaming Company remakes, and pinball classics — with shot-path guides and goal-by-goal breakdowns for each one. The machine index lists every machine currently covered.

How the guides are written

Every goal description and shot-path diagram in Pinball Genie is original instructional text and original schematic artwork, written and drawn for this app. Pinball Genie ships no manufacturer artwork, logos, audio, or game code. Machine and manufacturer names appear only as plain text, used solely to identify which physical machine a guide is for — see our Terms for how we think about that.

Who's behind it

Pinball Genie is an independent, solo-built project operated by Pinball Genie LLC. It is not affiliated with, endorsed by, or sponsored by any pinball manufacturer or theme rights holder.
